About This Workbench

Local workbench for canonical notarization record inspection, transaction composition, and receipt export.

It composes deterministic private-transfer-burn transactions through Rust-only canonical builders, derives burn and notary artifacts, and renders the existing canonical summary plus Markdown / HTML receipts.

It does not perform blockchain submission, production wallet integration, or browser-side signing. It can prepare frozen authorization requests for external signers and expose a local dev signer for local-only testing.
