# Reports Directory

**Classification:** `SUPPORTING / NON-AUTHORITY`

This directory contains generated verification reports and research outputs. These files are not authoritative protocol definitions.

## Generated Reports

The following are regenerated by the verification pipeline and are gitignored:

- `*.json` — Machine-readable verification outputs
- `LAST_RUN.md` — Execution log from the last realignment pass

## Committed Reports

The following are committed intentionally as human-readable reference:

- `AURA_MANUAL_PIPELINE_WALK_V1.md` — Human-readable pipeline walkthrough output
- `AURA_521_BIT_COMMITMENT_BIAS_AUDIT_V1.md` — 521-bit commitment bias audit
- `AURA_521_BIT_COMMITMENT_GROVER_RESEARCH_V1.md` — Grover algorithm research
- `AURA_ADVERSARIAL_AUDIT_V1.md` — Adversarial audit findings
- `AURA_CANONICAL_ALIGNMENT_FIX_V1.md` — Canonical alignment fix log
- `AURA_CRATE_AUDIT_CANONICAL_ALIGNMENT_V1.md` — Crate audit results
